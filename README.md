# ✊ Jokenpô em Python

Um jogo simples de **Jokenpô (Pedra, Papel e Tesoura)** desenvolvido em Python para praticar lógica de programação, estruturas condicionais, entrada de dados e geração de escolhas aleatórias.

## 🎮 Sobre o projeto

Neste jogo, o jogador escolhe entre:

* 🪨 Pedra
* 📄 Papel
* ✂️ Tesoura

O computador faz uma escolha aleatória e, em seguida, o programa verifica quem venceu a rodada.

### 🏆 Regras

* 🪨 Pedra vence ✂️ Tesoura
* 📄 Papel vence 🪨 Pedra
* ✂️ Tesoura vence 📄 Papel
* Escolhas iguais resultam em empate.

## 🛠️ Tecnologias utilizadas

* **Python 3**
* `random`
* `rich`

## 📚 Conceitos praticados

Este projeto foi desenvolvido para praticar:

* Geração de números aleatórios

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/VictorLCM1227/jokenpo-python.git
```

### 2. Entre na pasta do projeto

```bash
cd jokenpo-python
```

### 3. Execute o programa

```bash
python jokenpo.py
```
